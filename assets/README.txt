ASSETS FOLDER
=============

This folder contains your portfolio assets:

1. Resume:
   - Add your resume as "resume.pdf" in this folder
   - The download button in the portfolio will automatically link to it
   - Path should be: assets/resume.pdf

2. Images (optional):
   - Add your profile photo here
   - Add project screenshots
   - Recommended image formats: JPG, PNG, WebP
   - Optimize images for web (compress before uploading)

3. Favicon (optional):
   - Add favicon.ico for browser tab icon
   - Path should be: assets/favicon.ico

TIPS:
- Keep file names lowercase and use hyphens (e.g., my-photo.jpg)
- Optimize images to reduce file size
- Recommended profile photo size: 400x400px or 500x500px
- Keep total assets folder under 5MB for fast loading
